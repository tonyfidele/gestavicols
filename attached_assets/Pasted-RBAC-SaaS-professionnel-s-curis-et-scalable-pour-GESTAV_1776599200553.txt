AJOUT AU schema.prisma
Ajoute ceci dans ton schema :







ENUM PERMISSIONS
enum PermissionAction {
  CREATE
  READ
  UPDATE
  DELETE
  APPROVE
  EXPORT
}

TABLE PERMISSION
model Permission {
  id        String   @id @default(uuid())
  resource  String   // ex: "BATCH", "SALE", "STOCK"
  action    PermissionAction
  createdAt DateTime @default(now())

  rolePermissions RolePermission[]
}

TABLE ROLE PERMISSION
model RolePermission {
  id           String   @id @default(uuid())
  role         UserRole
  permissionId String

  permission   Permission @relation(fields: [permissionId], references: [id])

  @@unique([role, permissionId])
}

OPTIONNEL : PERMISSION PERSONNALISÉE PAR UTILISATEUR
model UserPermission {
  id           String   @id @default(uuid())
  userId       String
  permissionId String

  user         User @relation(fields: [userId], references: [id])
  permission   Permission @relation(fields: [permissionId], references: [id])

  @@unique([userId, permissionId])
}

4️ MIDDLEWARE BACKEND SÉCURISÉ (CRITIQUE)
Dans Next.js API :
Étape 1 : Middleware Auth
export async function getUserFromToken(req) {
  const token = req.headers.authorization?.split(" ")[1]
  if (!token) throw new Error("Unauthorized")

  const decoded = verifyToken(token)

  return {
    userId: decoded.userId,
    tenantId: decoded.tenantId,
    role: decoded.role
  }
}

Étape 2 : Vérification permission
export async function checkPermission(user, resource, action) {
  if (user.role === "SUPER_ADMIN") return true

  const permission = await prisma.rolePermission.findFirst({
    where: {
      role: user.role,
      permission: {
        resource,
        action
      }
    }
  })

  if (!permission) {
    throw new Error("Forbidden")
  }

  return true
}

5️ ISOLATION MULTI-TENANT RENFORCÉE
Option avancée (niveau bancaire) :
Créer une fonction utilitaire :
function withTenant(user, where = {}) {
  return {
    ...where,
    tenantId: user.tenantId
  }
}
Utilisation :
await prisma.sale.findMany({
  where: withTenant(user)
})

 7️ PROTECTION AVANCÉE
1️ Protection contre escalade de privilège
Ne jamais faire confiance au role envoyé par frontend.
Toujours lire depuis DB ou token signé.

2️ Protection modification tenant
Ne jamais accepter tenantId venant du frontend.
Toujours :
tenantId: user.tenantId

3️ Soft delete sécurisé
Ajouter :
deletedAt DateTime?
Et filtrer :
where: {
  deletedAt: null
}

8️ PERMISSIONS GRANULAIRES PAR FERME (OPTION AVANCÉE)
Si tu veux ultra-pro :
Ajouter table :
model FarmAccess {
  id        String @id @default(uuid())

  farmId    String

  user      User @relation(fields: [userId], references: [id])
