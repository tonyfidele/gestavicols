1 ARCHITECTURE SAAS MULTI-TENANT 
Shared database – Shared schema – tenant_id
Toutes les tables métiers contiennent :
tenant_id UUID NOT NULL
•	Chaque entreprise = 1 tenant
•	Isolation logique par tenant_id
•	Index composite (tenant_id, id)

2️ MODÈLE GLOBAL DU SYSTÈME
Structure hiérarchique :
Entreprise (Tenant)
→ Fermes
→ Bâtiments
→ Bandes
→ Suivi journalier
→ Ventes / Stocks / Finances / Vétérinaire




3 MODÈLE DE BASE DE DONNÉES COMPLET

4️ RELATIONS CLÉS
•	tenant → farms (1-N)
•	farm → buildings (1-N)
•	building → batches (1-N)
•	batch → daily_records (1-N)
•	batch → veterinary_records (1-N)
•	farm → sales (1-N)
•	tenant → users (1-N)
